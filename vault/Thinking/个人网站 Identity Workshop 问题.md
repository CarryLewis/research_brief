## Extended Reflection

这条记录不是在回答个人网站 About 页的问题，而是在保存一组之后可以慢慢回答的 Identity Architecture Workshop 问题。

核心目标：不是写一篇显得厉害的 About Me，而是寻找一个足够真实、稳定、能够支撑未来几年发展的个人核心叙事。

## Workshop 总结构

这组问题可以整理成五层：

1. Identity — 我是谁？

- 不是职业、学校、项目、技能，而是这些外在身份被拿走之后，还剩下什么。

- 关键词可能包括：观察者、建造者、问题驱动的人、系统思考者、探索者、不断重构自己的人。

1. Curiosity — 我到底在探索什么？

- 不只是列兴趣爱好，而是寻找 Medicine / AI / Knowledge Systems / Philosophy / Religion / Software 等兴趣背后的 common denominator。

- 可能的方向：复杂系统、人体系统、信息与智能系统、意义与意识系统、人类协作系统、人造系统。

1. Philosophy — 我相信什么？

- 不是名言，而是 operating principles。

- 也就是：当没有人告诉我该怎么做时，我依据什么做决定。

1. Story — 我是怎么走到这里的？

- 不是完整 autobiography，而是寻找 turning points。

- 特别关注：医学 → 发现某种限制 → 寻找工具 → AI / coding → 建立自己的 systems 这条可能的因果链。

1. Relationship — 我希望谁来到这里？

- 个人网站不是静态简历，而是一个 interface between me and the outside world。

- 需要决定谁会来到 CarryLewis.com，以及他们来了之后希望发生什么。

## 22 个问题整理

### 01 — Identity：我是谁？

Q1. 如果只能用 3 个词描述现在的自己，你会选什么？
不要考虑高级不高级。

Q2. 你觉得自己和大多数同龄人的最大区别是什么？
不一定是优点。比如：总是在想“为什么”；很难只使用一个工具而不去思考它背后的系统。

Q3. 你什么时候最像“自己”？
可能是在独自思考、写代码、阅读、临床观察患者、跑步、深入讨论、旅行或观察陌生环境的时候。

Q4. 什么事情即使没人要求你，你还是会主动做？
这通常比“我的兴趣是什么”更能揭示身份。

Q5. 你希望别人离开你的网站之后，对你留下哪一个印象？
只能选一个最核心的印象。比如：好奇、会构建系统、真的在思考、正在尝试把医学和技术连接起来。

Q6. 如果 10 年以后回头看现在的 Carry，你希望别人说：
“他一直都是一个 ________ 的人。”

### 02 — Curiosity：我到底在探索什么？

Q7. 为什么你会同时对医学、AI、知识系统、哲学、宗教、软件感兴趣？
不要回答“因为我都喜欢”，而是追问：它们有什么共同之处？

Q8. 你遇到一个陌生事物时，第一个自然反应是什么？
比如：它为什么会这样？背后的机制是什么？有没有更好的方式？这些东西之间有没有联系？如果从 first principles 重新设计呢？

Q9. 你真正无法停止思考的几个问题是什么？
不是“我要学什么”，而是：What questions keep coming back?
可能包括：人如何理解世界？AI 如何改变人的认知？医学到底应该如何理解疾病？知识如何从 information 变成 understanding？人为什么需要 religion / meaning？

### 03 — Philosophy：我相信什么？

Q10. 当别人告诉你一个“标准答案”时，你通常会怎么做？
接受、怀疑、找证据、自己重新做一遍，还是寻找更底层的解释？

Q11. 你为什么喜欢 First Principles？
不是因为别人喜欢，而是它对我个人有什么价值。

Q12. 你怎么看“学习”？
A. 学习是获得更多知识。
B. 学习是建立知识之间的联系。
C. 学习是改变自己的 mental model。
D. 学习是获得理解世界的能力。
E. 都不是。

Q13. 你怎么看“Building”？
为什么不是只阅读、思考、写文章，而是不断做 Cursor / Coding / ECG Simulator / Knowledge System / Website / HTML Lab？
“做东西”对于理解有什么意义？

Q14. 你允许自己“没有答案”吗？
我是 Answer collector、Question explorer，还是 Hypothesis builder？

### 04 — Story：我是怎么走到这里的？

Q15. 有没有一个时期，我突然意识到：我不想按照传统路径生活？
是什么时候？发生了什么？

Q16. 为什么选择医学？
不要只回答“因为喜欢帮助别人”，而要尝试回答真正原因：人体复杂性、疾病机制、临床推理、家庭影响、偶然选择、后来逐渐喜欢，或其他。

Q17. 为什么后来开始进入 AI / Coding / Knowledge Systems？
这里可能存在一条重要故事线：医学 → 发现限制 → 寻找工具 → AI / coding → 建立自己的 systems。

Q18. 做 ECG Simulator、Knowledge Observatory 这些项目时，真正想解决的是什么？
不是“我想做一个 ECG simulator”，而是：为什么我觉得这个东西值得被重新做一遍？

Q19. 如果没有 AI / Cursor / Notion / Obsidian 这些工具，我还会不会做这些事情？
如果会，说明工具不是 identity，而只是 medium。

### 05 — Relationship：我希望谁来到这里？

Q20. 我希望谁来到 CarryLewis.com？
可能包括：Researchers、Builders、Thinkers、Medical students、Potential collaborators。

Q21. 我希望他们来到这里之后做什么？
可能路径：Read → Think → Contact；Explore → Discover a project → Collaborate；Explore my thinking → Understand me → Start a conversation。

Q22. 我希望别人联系我时，是什么类型的消息？
比如：I want to work with you；I read your thinking about X and disagree；I want to collaborate on this project；I have an idea。
